# Windows 与 macOS 打包

此项目使用固定 Electron 44.7.2 运行环境，将应用源代码放入运行环境的 `resources/app`（Mac 为 `Contents/Resources/app`），并附带对应架构的独立 FFmpeg。构建脚本只使用 Node.js 内建模块和系统工具，不需要 npm 打包依赖、Wine 或 Windows 编译器。

## 构建命令与产物

在 macOS 构建机运行，需要 Node.js 20 或更新版本，以及系统自带 `unzip`、`ditto`、`plutil`、`lipo`、`otool`、`codesign`。

```sh
node scripts/package.mjs --target all --offline
node scripts/package.mjs --target darwin-arm64 --offline
node scripts/package.mjs --target darwin-x64 --offline
node scripts/package.mjs --target win32-x64 --offline
```

省略 `--target` 时生成全部三种架构。省略 `--offline` 时允许从下列固定上游补充缺失缓存；软件正常使用时不会执行这些下载。

| 目标 | ZIP | 默认保留的解压目录 |
|---|---|---|
| Windows 10/11 x64 | `dist/QQ音乐转MP3-Windows-x64.zip` | `dist/QQ音乐转MP3-Windows-x64/` |
| Mac Apple Silicon | `dist/QQ音乐转MP3-macOS-arm64.zip` | 系统临时目录中独立的 `qq-mp3-unpacked-darwin-arm64-*/QQ音乐转MP3-macOS-arm64/QQ音乐转MP3.app` |
| Mac Intel | `dist/QQ音乐转MP3-macOS-x64.zip` | 系统临时目录中独立的 `qq-mp3-unpacked-darwin-x64-*/QQ音乐转MP3-macOS-x64/QQ音乐转MP3.app` |

每个 ZIP 均附带同名 `.sha256`。默认保留解压目录，日志输出准确绝对路径，便于在当前 Apple Silicon Mac 上启动原生 ARM App 验收；用 `--no-unpacked` 只保留 ZIP。Mac 最低系统版本以所用 Electron App 的 `Info.plist` 中 `LSMinimumSystemVersion` 为准。

## Mac FFmpeg 的来源与校验

两种 Mac 架构使用不同的已固定发行，实际 FFmpeg 版本分别记录，不将分发标签当作实际程序版本。

## App 结构、签名与验收边界

Windows 保留完整 Electron DLL、locale、ICU 和 V8 资源，主程序重命名为 `QQ音乐转MP3.exe`。Mac 主包重命名为 `QQ音乐转MP3.app`，主可执行文件同名；修改 `CFBundleIdentifier` 为 `com.local.qqmp3`，并同步主版本、显示名称和辅助 App 的标识。FFmpeg 位于应用源根目录的 `resources/ffmpeg` 或 `resources/ffmpeg.exe`。

Mac 先对包内 Mach-O 与嵌套 App/Framework 从内到外做本地 ad-hoc 重签名。原始代码存在签名时保留其 entitlements，不杜撰新的 entitlement；随后执行 `codesign --verify --deep --strict`。签名信息、来源哈希及重签名后的二进制哈希记入 `BUILD-MANIFEST.json`。

Mac 在系统临时目录中组装、签名、创建 ZIP 并验证，再将最终 ZIP 搬到项目 `dist/`；原生验收 App 也留在系统临时目录。这样避免项目所在 CloudStorage 文件提供方在签名期间重新附加 Finder 元数据。仅对新组装 App 清除与签名不兼容的 `com.apple.FinderInfo` 和 `com.apple.ResourceFork`，保留 quarantine 和系统信任设置。

Mac ZIP 使用系统 `ditto -c -k --sequesterRsrc --keepParent`，保留 App 可执行权限和 Framework 符号链接。归档完成后先完整解压复验，再检查严格签名、主程序与 FFmpeg 可执行权限、Framework 符号链接和目标架构，通过后才交付 ZIP。Windows ZIP 使用 Node 内建流式写入器，明确设置中文文件名 UTF-8 标志。

本地 ad-hoc 签名验证不等于 Apple Developer ID 签名、公证或 Gatekeeper 放行；此脚本不上传 Apple 服务，不宣称已通过这些分发检查。ARM App 可在本机实际启动验证；Intel Mac 与 Windows 包在缺少相应实机运行时只能完成归档、来源与布局检查，不能写成已做实机验收。
