## 普通 FLAC 新增验收

直接添加 `.flac` / `.FLAC`，真实执行 320 / 256 / 192 kbps、44.1 kHz 转码，保留中文歌名、歌手和专辑。原始 FLAC 字节与 mtime 均不变；验证伪文件头、损坏帧、重名、两阶段取消均符合预期。文件夹扫描和原生选择器接受 FLAC，可与加密文件混合批量；LRC 按用户要求不处理。最新 ARM 成品已用包内 Electron 44.7.2 / Node 24.21.0、转换模块和 FFmpeg 实际转换普通 FLAC，输出完整解码、中文标签和源文件字节检查均通过；主程序及渲染子进程启动检查通过。新增普通 FLAC 的原生窗口交互未单独完成：计算机操作工具发现/启动 App 时发生长等待，未把模拟检查冒充原生 GUI 验收。此前三首 QMC 的原生 GUI 验收已通过。
